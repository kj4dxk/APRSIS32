Updates to the Wiki page are needed at:  
doc:queries

add: **?APRS** - Receiving station responds with packets showing QUERY Support available from APRSISCE program software  
e.g. Support[1/2]: ?APRSD ?APRSL ?APRSH ?APRSM ?APRSO ?APRSP ?APRSS  
Support[2/2]:?APRST/?PING? ?ABOUT/?APRSV/?VER ?CPU ?DX ?IGATE

add: **?CPU** - Receiving station responds with packet showing Computer Processor Unit (CPU) using the APRSISCE software  
e.g. APRSIS32 Windows v6.1 b7601 p2 K:30.9/5.0% U:3.7/0.6%

==  
KC6VVT derived by experimentation with sending queries from mobile to HOME station that revealed these 2 undocumented query commands.
