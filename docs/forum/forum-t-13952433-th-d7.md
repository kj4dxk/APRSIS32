Possible to enable TNC on init. TH-D7A(G)

[![K9BFG](../archive/assets/avatar--17545b62bdbe.php)](https://www.wikidot.com/user:info/k9bfg)[K9BFG](https://www.wikidot.com/user:info/k9bfg) 23 Dec 2020 07:11

<span id="post-content-4851610"></span>

It is possible to enable the TNC when enabling the port, rather than turning on the TNC manually before connecting with APRSIS32. Not all of the commands seem to elicit a response/change on the radio. Tested on TH-D7A(G) using codes from:  
ta1dx's /kenwood/thd7kom.htm page on qsl.net

```
<OpenCmd>^C^C^C~!!0</OpenCmd>
<OpenCmd>^192^255^192~!!0</OpenCmd>
<OpenCmd>TC 1</OpenCmd>
<OpenCmd>TNC 2</OpenCmd>
<OpenCmd>BC 0</OpenCmd>
<OpenCmd>DTB 0</OpenCmd>
<OpenCmd>TC 0</OpenCmd>
<OpenCmd>^M~</OpenCmd>
<OpenCmd>^M~</OpenCmd>
<OpenCmd>XFLOW OFF</OpenCmd>
<OpenCmd>FULLDUP OFF</OpenCmd>
<OpenCmd>KISS ON</OpenCmd>
<OpenCmd>RESTART!!0</OpenCmd>
```
