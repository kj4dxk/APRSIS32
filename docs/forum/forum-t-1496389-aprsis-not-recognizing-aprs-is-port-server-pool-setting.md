Greetings. Relative rookie APRSIS/32 user here.  
I am having an issue whereby my installation is not following the APRS-IS port server pool setting. I have it set to bc.aprs2.net yet all my packets appear to be being sent to T2TOKYO2. This is causing errors as some packets are being received out of sequence.  
Installation was a Windows 7 box and has since been upgraded to Windows 10. The problem was apparent on both platforms.  
This is the error others are seeing…  
2015-12-29 15:07:06 PST: VE7EQN-1>BEACON,VE7RSS\*,VE7RKA\*,WIDE2\*,qAR,VE7RXD-9:T#865,143,145,072,041,118,00010011 [Duplicate telemetry sequence]  
Here is what APRS-IS seems to know about my station…  
2015-12-29 03:50:42 PST: VE7RXD-9>APWW10,TCPIP\*,qAC,T2TOKYO2:@115044h5042.82NI12022.54W#APRS-IS for Win32  
2015-12-29 03:52:41 PST: VE7RXD-9>APWW10,TCPIP\*,qAC,T2TOKYO2:<IGATE,MSG\_CNT=0,LOC\_CNT=22,DIR\_CNT=5,RF\_CNT=33,DX=1707\*VE7RKA-5(14mi@239<0xb0>)

Any ideas?
