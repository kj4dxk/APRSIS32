There is no filter on received packets. Per <http://www.aprs-is.net/IGateDetails.aspx>

"Gate all packets heard on RF to the Internet EXCEPT if any of the following are true…"

And none of the exceptions have anything to do with the ISS.

That said, there is a recent move afoot to provide for not gating directly received (ie no hops used) packets specifically for the purpose you describe. I'll hopefully get around to implementing that (relatively) soon.
