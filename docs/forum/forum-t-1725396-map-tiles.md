As stated at the wiki page mentioned above, APRSISCE/32 only supports OSM-compatible map tiles named the same as they name them. Check the directory tree for one of your map tile sets and you'll see the files that need to be available for the maps to be displayed by APRSISCE/32. I suspect that GeoFabrik doesn't support that particular format in their downloads.

<span id="post-content-2519733"></span>

Geofabrik maps are OSM data, not OSM-compatible map tile. They offer downloads of the raw OSM data (extracted, so you don't have to download the entire planet) and shapefiles. The OMS data is what you'd feed into a map server that would render tiles from that data. Shapefiles are supported by some mapping software, but not APRSISCE/32.
