Problem solved! I needed to get a few things straightened out.  
Start with netbook or laptop hardware and establish the com port configuration,  
next setup the program to use those settings,  
next configure the radio to use those settings, check Menu 528 to make sure it is set for the same speed as virtual com port,  
next turn on the com port in Menu 604,  
and last but not least you may have to toggle the radio TNC button from APRS to Packet mode.  
This has me up and running so now I can play with my settings to optimize the program for my needs.
