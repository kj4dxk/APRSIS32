Not any time soon. I've got some ideas in mind for advanced display filtering, but they're primarily focused on whitelisting stations for events (thing Tag and View/Tags).

If a station is being received on RF, just making it not appear on the map isn't doing anything to fix the RF environment. If the station is truly operating in a community-unfriendly manner, there are procedures in place for attempting to get the source of the situation corrected (always short of pinning coax).
