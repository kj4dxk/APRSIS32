APRSIS32 already posts a Windows Notification which is designed for that purpose. I'm kind of hesitant to make the task bar flash because many of us get LOTS of messages and only answer them when we're able.

Lynn (D) - KJ4ERJ - Author of APRSISCE for Windows Mobile and Win32

PS. I'm aware of the FlashWindow function. If you select text in a scrolling log and more messages want to go there, the window will start flashing as the new text is buffered so as not to disrupt your selection. If you minimize a scrolling log and new text arrives, it will also flash on the task bar.
