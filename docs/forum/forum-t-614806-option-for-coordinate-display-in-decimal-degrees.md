<span id="post-content-1684229"></span>

It would be nice if there was an option in the configuration to enable display of coordinates in decimal degrees (dd.ddddd) throughout the entire program. This would allow the user to quickly copy & paste into other programs / websites without having to manually calculate/convert.

Also add copy to clipboard option on right-click of text-containing screen information elements enabled by Configure->Screen (Grid Square, Lat/Long, etc)

I do have hopes/plans to support multiple coordinate formats for both entry and display in some future version.

I'll add the option to copy textual screen elements to the clipboard as well. Currently all pop-up text windows (like the station information box) can be copied to the clipboard with a Control-C (for Copy). This also works to copy the map display to the clipboard for pasting into a graphics program like IrfanView or directly into an e-mail message.
