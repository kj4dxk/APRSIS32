Or switch to the development version as it's far more up to date. The General release is getting a bit long in the tooth now. Switching to the development version does need an xml config edit though.

Going "forth" (from general to development) is the recommended path and attempts are made to automatically upgrade any changes to the XML configuration file.

Going "back" (from development to general) is strongly discouraged, even to the point of receiving a warning if a regression in version is detected. You may lose configuration settings if you go backwards in version dates.
