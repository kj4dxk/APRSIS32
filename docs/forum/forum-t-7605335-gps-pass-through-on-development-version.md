Hi

After working to rebuild my balloon tracking computer after a catastrophic crash, I was unable to get the program to recognize the GPS data passed through by my D710. I've spent hours and was beginning to doubt my sanity (a topic for another thread). ;-) I knew it had worked previously and I remember it was very easy to set up. Try as I might, it just wouldn't work. My backups showed I was running the last production version but I could swear that I as running the development version because I run it everywhere else. Finally I gave in and switched to the production and the feature sprang to life.

My question is whether this capability exists in the development version or not.
