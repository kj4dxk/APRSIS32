I am wondering why it seems no one reads / uses / comments about this software. This is by far the most amazing software for APRS that I have encountered so far.. I have been using APRS-SA for YEARS and I did and still do really like it, BUT, with that being said this particular software has many more detailed settings, capabilities, etc. than the APRS-SA has, more so, since the author of APRS-SA has ceased to update/upgrade. If you get this APRSISCE configured properly, it is truly a powerful program and COULD BE, a benefit to all of Amateur Radio in my opinion.. Have a Great Day..
