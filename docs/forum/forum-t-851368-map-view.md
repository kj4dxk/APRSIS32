2) Does your laptop have unrestricted Internet access? The chiming sounds like it is attempting, and failing, to open a connection, likely to the APRS-IS server?

Sounds like you've got it all going. Congrats!

APRSISCE/32 considers it an issue if it cannot open a port which is configured and enabled, so it generates noise. Some folks would like to just leave a port (like APRS-IS or BlueTooth connected) enabled at all times and expect APRSISCE/32 to establish the connection when it is able, but without the sound, you'd never know if it was having trouble when it SHOULD have been connected. So it makes noise.
