Have you seen the wiki at [Related manual page](../manual/wiki-home.md)

In particular: [Related manual page](../manual/doc-screen-elements.md)

I think you're asking about:

1, on the right hand side of the map there is a column that goes up and down and changes colors.

That's likely 19 showing the active station count. If you double-click it, it reveals more details.

2, at the top left hand side there is a box that call signs scroll up, but but from there is three lines  
that shoot out and sometimes goes the with of the screen, and again there is three colors.

Actually, the three thin lines are part of the box above, not the packet scroller. That's number ??? but it's not documented yet. They represent various timers in the program whose details escape me at the moment. One jumps long and then shrinks down as the minimum time between beacons is satisfied. One slowly grows until the next timed beacon, and the third completely escapes me!

3, top middle of the screen is aprs-is OK and (in my case) Steve OK flashes but also it is flashing "close-cmd"  
every so often, so what does this mean ?

Close-Cmd is not something you want to see because it indicates that you've got a port that is closing and re-opening periodically. Steve must be what you called your RF port, and I suspect it's not working the way you'd really like it to. Do you see any \* on packets as they scroll by? If so, those are received from an RF port. If not, then you're only receiving packets via the APRS-IS.

Questions like these are better handled in the APRSISCE Yahoo group if you join that. There's a link to it from the main Wiki page.

I think I replied on the yahoo group  
APRSIS32 monitors the RF port if it does not see a packet within the quiet set in configure general (default 60 seconds) it assumes the TNC has dropped out of KISS mode, and attempts to put it back. By running the open close commands, set quiet time to a higher value if you are not seeing many packets, or set to 0 which disables it.  
If you are seeing plenty of packets and it is still cycling you have a different issue
