# 2011/08/21 16:57

**Minor Fixes in APRSISCE6P110821.zip and APRSIS32110821.zip**

About version is 2011/08/21 16:57

1) Previously released fix for the over-zealous automatic r/lat/lon/range filters for MultiTracks.

2) "RANGING" should not be showing up in the main window any more. It is ALWAYS ranging!

3) "Center" on a station's popup menu no longer clears the center to jump back to ME. It now always centers on the station whose popup menu it is found on, whether checked or not. Use "Center ME" or Screen / Follow / ME to start following your own station.

And everything in the [2011/08/20 02:06](2011-08-20-02-06.md) release as well
