# Quick Keys

APRSISCE/32 has a few key strokes which access various actions. Rather than go through the menu system

| Key Press | Action |
| --- | --- |
| CTRL Q | Exit the software |
| CTRL O | Basic Amateur Satellite pass info (in development) |
| CTRL P | Test APRS packet |
| CTRL A | About window (check for updates) |
| CRTL F | Find a station |
| CTRL G | Enter a test IS filter |
| CTRL Z | Enter a shape file Zone/County |
| CTRL X | Exit the software |
|  |  |
| Left Arrow | Increase Map Opacity |
| Right Arrow | Decrease Map Opacity |
| Up Arrow | Zoom Out |
| Down Arrow | Zoom In |
