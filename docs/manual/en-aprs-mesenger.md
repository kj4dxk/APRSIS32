# EN_APRS_Mesenger

## APRS Messenger

APRS Messenger can act as a APRS server on ports 8062 and 8063.  
So all modes supported by APRS Messenger can be used by APRSISCE/32 to supply a mapping function to APRS Messenger, amongst other features.  
of course it can be configured the with APRS messenger being the client on port 14580 connecting to APRSIS32.
