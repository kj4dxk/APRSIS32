# EN_FreqMon

## Frequency Monitor

The Frequency Monitor window displays the last received frequency comment from an object or station.  
The Monitor shows the station and the comment, and attempt to check the comment against the spec highlighting and errors, in the hope that these will be corrected.  
Right clicking on the monitor window also setting of a filter to restrict the stations, showing. And an auto timer to shut down the window after a period of time.  
To disable the monitor go to enable frequency monitor with the window open and untick it. With the window closed it will just pop back on.
