# EN_PassResp

## Passcode Response

Thank you for requesting a passcode for **APRSISCE/32**  
We aim to respond to passcode requests as quickly as possible and to that end, have members in the USA, UK and NZ. In an effort to cover as many of the main time zones, As possible.  
Usually a passcode is sent out within a couple of hours, if however you have not received a message within a day, it's likely something went wrong, please request again, stating in the comment field, that you have not received a code from your first request.

The passcodes are not required to use the software, they are APRS-IS login codes, and are only required if you wish to send to the Internet APRS stream.
