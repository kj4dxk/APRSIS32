# Enables1

[Source wiki page](https://aprsisce.wikidot.com/enables1) · [Archived HTML](../archive/pages/enables1--2519f644cafa.html) · [Source license](http://creativecommons.org/licenses/by-sa/3.0/)

The Enables menu allows you to Enable (and Disable) various settings within APRSISCE/32. Currently the [TraceLogs](https://aprsisce.wikidot.com/tracelogs) are also accessed via this menu.

APRS-IS Enabled

APRS-IS Enabled

> When checked, enables a live connection to the APRS-IS server configured. Requires that Internet Access also be enabled.

AutoSave GPX

AutoSave GPX

> When checked, a .GPX file is automatically saved containing your recorded track if your station moves. The file will be named <callsign-SSID>-YYYYMMDD-HHMM.gpx and stored in the same directory as the XML configuration file.

Beaconing Enabled

Beaconing Enabled

> When checked, allows APRSISCE/32 to generate position reports (beacons) for transmission via all enabled ports.

CSV Enabled

CSV Enabled

> When checked, causes APRSISCE/32 to write a YYYYMMDD-HHMM.csv (Comma-Separated Values) file containing each unique location where a position report was triggered. CSV file is written regardless of the Beaconing Enabled setting.

GPS Enabled

GPS Enabled

> When checked, enables GPS access. When greyed out, a GPS port has not yet been configured via [Configure](menu-configure.md) / Ports / NMEA.

Internet Access

Internet Access

> When checked, enables Internet access by APRSISCE/32. Internet access is required for APRS-IS, Map Tile fetching, and Version update checking.

OSM Fetch Enabled

OSM Fetch Enabled

> When checked, enables the fetching of new map tiles if as required when one is not available in the local cache. Requires that Internet Access also be enabled.

Sound Enabled

Sound Enabled

> When checked, enables [sounds](sounds.md) generated by APRSISCE/32.

Telemetry Enabled

Telemetry Enabled

> When checked, enables telemetry packets transmission via configured ports. Internal telemetry reports are not affected by this switch.
