# Configure Metric

[Source wiki page](https://aprsisce.wikidot.com/menu:configure-metric) · [Archived HTML](../archive/pages/menu_configure-metric--9cd9936cc150.html) · [Source license](http://creativecommons.org/licenses/by-sa/3.0/)

|  |
| --- |
| **Configure Metric** |

|  |
| --- |
| This configure option selects which measurements you would like to display as a metric rather then imperial value. Defaults are imperial. **Altitude**  Selects between displaying altitude in feet (unchecked) or metres (checked)  **Distance**  Selects between displaying distance in miles (unchecked) or kilometres (checked)  **Pressure**  Selects between displaying atmospheric pressure in inches (unchecked) or milliBars (checked)  **Rainfall**  Selects between displaying inches (unchecked) or millimetres (checked)  **Temperature**  Selects between displaying temperature in Fahrenheit (unchecked) or Celsius (checked)  **Wind (Knots)**  Selects between displaying wind speed in mph (unchecked) or knots (checked). (not strictly a metric option) |
