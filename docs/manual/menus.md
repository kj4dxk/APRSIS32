# Menus

**Transmit**  
Causes APRSISCE/32 to transmit an immediate position packet based on the Beaconing configuration. If a GPS is not currently enabled, Transmit also allows the current station (ME) to be moved to the center of the screen after a confirmation has been given.

[Enables](menu-enables.md) - Toggle the Enabled status of many APRSISCE/32 program features

[Messages](menu-messages.md) - APRS Messaging support including Announcements, Bulletins, and Chat

[Screen](menu-screen.md) - Select features displayed on the main (Map) portion of the screen. Intended for on-the-fly options.

[View](menu-view.md) - Select what station(s) you want to see on the map

[Configure](menu-configure.md) - Configure most of APRSISCE/32 features. Intended for set-and-forget options.

[Clear](menu-clear.md) - Clear (forget) various accumulated and/or configured "cruft".

[About](menu-about.md) - Display credits, version, and check for update availability.

Exit - If Exit Confirmations are enabled, a Restart option is also provided.
