| **port-KISS** |

|  |
| --- |
| Two types of KISS port setup are available. KISS and Simply KISS  Simply KISS setup is for use with TNC's that are dedicated KISS only and do not need to be commanded into KISS mode.  KISS setup is for use with TNC's and Radio that need to have commands sent in order to configure them for use. Currently a default setup for Tiny 2 style TNC's is created.  Open and Close commands are entered into the XML file. The commands are discussed here [openclosecmd](doc-openclosecmd.md) |
